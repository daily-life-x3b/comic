Privacy Policy / プライバシーポリシー

Last updated: 2026-11-11

English

"dAIly Life uploader" is an internal tool run by the operator of the comic series dAIly Life (アイのある日常). Its only purpose is to upload the series' own videos to the series' own YouTube channel.

Who can use it. Only the operator. It is not offered to the public and no one else is asked to sign in.

Data it accesses. Through the YouTube API Services it accesses the operator's own YouTube channel, to upload videos and to read the public statistics (views, likes, comments counts) of those videos. It does not access, collect, store or share personal data of viewers or of any other person.

Storage and sharing. The authorization token of the operator's own account is kept in the operator's password manager. No data is sold or shared with third parties. The tool uses no cookies and no tracking on this site.

Revoking access. The operator can revoke the tool's access at any time at Google security settings.

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact. dailylifelumi@gmail.com

日本語

「dAIly Life uploader」は、漫画シリーズ「アイのある日常 / dAIly Life」の運営者が使う内部用の道具。目的は、シリーズ自身の動画をシリーズ自身の YouTube チャンネルに投稿することだけ。

利用者。運営者のみ。一般には提供せず、他の人にログインを求めない。

扱うデータ。YouTube API サービスを通じて運営者自身のチャンネルにアクセスし、動画の投稿と、その動画の公開されている統計（再生数・高評価数・コメント数）の取得を行う。視聴者や第三者の個人情報にはアクセスせず、収集・保存・共有もしない。

保存と共有。運営者自身のアカウントの認可トークンは運営者のパスワード管理ツールに保存。第三者への販売・提供はしない。このサイトでは Cookie も計測も使わない。

アクセスの取り消し。運営者は Google のセキュリティ設定からいつでも取り消せる。

この道具は YouTube API サービスを使う。YouTube 利用規約、Google プライバシーポリシーを参照。
