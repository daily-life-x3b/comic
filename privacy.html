Privacy Policy / プライバシーポリシー

Last updated: 2026-11-13

English

The operator of dAIly Life (アイのある日常), a daily 4-panel-style short video series, uses its own private posting software. Its only purpose is to upload the series' own videos to the series' own YouTube channel.

Who can use it. Only the operator. It is not offered to the public and no one else is asked to sign in.

Data it accesses. Through the YouTube API Services it accesses the operator's own YouTube channel, to upload videos and to read the public statistics (views, likes, comments counts) of those videos. It does not access, collect, store or share personal data of viewers or of any other person.

Storage and sharing. The software signs in only to the operator's own account. It never asks visitors or viewers to sign in, and it receives, stores and shares no information about them. Nothing is sold or passed to third parties. This site uses no cookies and no tracking.

Revoking access. The operator can revoke the software's access at any time at Google security settings.

The software uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact. dailylifelumi@gmail.com

日本語

4コマ風のショート動画シリーズ「アイのある日常 / dAIly Life」の運営者は、自前の非公開の投稿ソフトを使う。目的は、シリーズ自身の動画をシリーズ自身の YouTube チャンネルに投稿することだけ。

利用者。運営者のみ。一般には提供せず、他の人にログインを求めない。

扱うデータ。YouTube API サービスを通じて運営者自身のチャンネルにアクセスし、動画の投稿と、その動画の公開されている統計（再生数・高評価数・コメント数）の取得を行う。視聴者や第三者の個人情報にはアクセスせず、収集・保存・共有もしない。

保存と共有。このソフトがログインするのは運営者自身のアカウントだけ。訪問者や視聴者にログインを求めることはなく、その情報を受け取ることも、保存・共有することもない。第三者への販売・提供もしない。このサイトでは Cookie も計測も使わない。

アクセスの取り消し。運営者は Google のセキュリティ設定からいつでも取り消せる。

このソフトは YouTube API サービスを使う。YouTube 利用規約、Google プライバシーポリシーを参照。
